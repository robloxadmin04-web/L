Protection tuning

Integrity check mode

What happens when a delivered script detects a hooked loadstring/HttpGet/require/pcall. Start on "Log only" for a few days to confirm no false positives on your userbase's executors, then switch to "Kick".

Execution ticket TTL (seconds)

How long a delivered script has to redeem its single-use execution ticket. Raise this if legit players on slow connections are getting "expired session token" errors. Range: 5-120s.

Loader rate limit (requests/min per IP)

Raise this if players sharing a public IP (school/office/carrier NAT) are getting rate-limited together. Lower it to clamp down harder on scraping. Range: 5-300.

Strict environment check

Adds one extra signal (getrenv() vs loadstring comparison) on top of the integrity check above. Catches a narrower class of hook, but confirmed to false-positive on some executors even with nothing wrong - off by default. Only turn this on if you've seen a specific hook get past the standard check.
